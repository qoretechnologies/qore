The numbers of the revision that the port of qore#5578's work starts from: `batch/aot-identity` 446db47e20 (AOT-1,
develop 5dda16d4bc merged), with this harness (`run.py` of this branch).  Each later port reports its kernel rows
against this table, measured the same way on the same hosts, and against the target in `RESULTS.md`.

- **Linux**: AMD Ryzen 9 9955HX (x86_64), Linux 7.0, GCC 15, LLVM 21; Release (`-O3 -DNDEBUG`) build of the `qore` and
  `qcc` targets, prefix `/usr/local`; run in a `qbuild --heavy` slot.
- **macOS**: Apple M4 Pro (arm64), macOS 27.2.1, Apple clang, LLVM 22; Release build of the same targets, prefix
  `/usr/local`; run in a `qbuild --heavy` slot (shared workstation).

Command (each host, with its build's `qore` and `qcc`):

```sh
python3 bench/runtime-comparison/run.py --modes qore-ast qore-ir qore-jit qore-aot \
    --count 4096 --forks 3 --warmup 3 --samples 3 --time-ms 300 --startup-samples 3
```

All four modes passed the 555 reference checks on both hosts before timing.  Values are whole-kernel ns/item, the
median of three process means (lower is better).  The target is macOS arm64 (M4 Pro) like the macOS column; source C
or M as in `RESULTS.md`.  The last column is the factor by which the AOT baseline is slower than the target; the target
