## Behavior, compatibility, and shared fixes

- Balance ping is an actual authenticated `GET /v1/user/balance`, including valid
  zero credit responses. Explicit `apikey` wins over `token`, including rejecting
  an explicitly empty/null key. Both client constructors, raw/future/copy paths,
  provider references/generic reads, and the media facade retain scope.
- Saved `stability-ai` URLs retain their scheme, placeholder localhost/x URLs migrate
  to the canonical service, explicit HTTPS origins are deliberate, and HTTP is
  restricted to loopback fixtures. Redirects and cross-origin authenticated copies
  are rejected. Ping and error diagnostics redact credentials, including echoed
  rejected keys and synchronous polling failures.
- Actual shared multipart encoding is used throughout. Binary, named file, base64,
  indexed legacy prompt parts, filenames, MIME parts, response negotiation, false,
  zero, and valid empty negative prompts are covered over localhost HTTP.
- Preflight rejects unknown/null fields, nonintegral seeds, invalid media sizes,
  incompatible model/mode inputs, dependent masks/references, outpaint with no
  extension, and audio duration/step constraints. Ultra's image input is available
  without SD3's mode selector; the compatible form and its wire path are tested.
- The old unsupported `4:3` and `3:4` choices are deliberately replaced by supported
  `5:4` and `4:5`. 139 of the original 141 presentation IDs remain; only those two
  obsolete choice IDs are removed. Other compatible identities are preserved.
- Responses preserve binary data, verified actual MIME, seed zero, finish reason,
  job identity, and Retry-After. Filtered output, error envelopes, MIME mismatch,
  HTML masquerading as images, and failed/mismatched pending jobs are rejected.
- Waits include setup and request time in the deadline, cap connect/request time,
  honor the production ten-second minimum and Retry-After, and preserve job/status
  on timeout. Independent concurrent waits are tested. Paid submissions are never
  retried automatically.
- Shared owners fix connection diagnostic sensitivity, blocking/polling REST
  redaction, GLB media handling, literal boolean-string encoding, decimal numeric
  boundaries, and millisecond-to-microsecond polling sleep conversion. Public
  numeric-bound members now use `softnumber`; numeric wire conversion is preserved.
- ProviderIndex/ProviderIndexUtil 1.2 preserve native serialized action type graphs,
  instead of dropping outputs and flattening inputs to primitive names. Structured
  serialization failure blocks publication and preserves the previous index. New
  indexes require the 1.2 reader; it continues to read legacy primitive-name indexes.
