## Connection and lifecycle findings

Both connection constructors now preserve the aws-textract scheme, derive regional defaults, identify
the app, and return typed sync/async clients. Explicit endpoints are retained, China endpoints use the
correct suffix, and a standard explicit endpoint determines its signing region ahead of environment
defaults. Service, JSON media type, and S3 signing mode are fixed for Textract.

Static key pairs are optional: inherited environment, ECS/IMDS and STS modes remain available.
The session token survives construction and copies. Credential resolution/AssumeRole happen at
client construction; callers recreate clients before temporary credentials expire. AWS CLI profiles
and SSO are resolved externally, not represented as an automatic SDK profile provider.

Ping requires a successful, structurally valid signed ListAdapters response. Invalid authentication,
authorization denials and malformed HTTP-200 results fail. ListAdapters permission does not prove
permission for other operations. Shared credential error messages no longer include partial credential
responses or rejected secret values.

Wire fixtures exposed and verified two shared fixes: synchronous HTTP must send the serialized bytes
without adding a charset after signing, and asynchronous HTTP must decode AWS JSON media types as UTF-8
JSON. Mime recognizes AWS JSON 1.0 and 1.1. Sync, async, copies, async futures and the injected generic
action are checked against actual loopback HTTP and independently recomputed SigV4 HMACs.

Adapter dropdowns are account/region scoped and paginate, rejecting repeated tokens or more than
100 pages. Version dropdowns depend on AdapterId. There is no AWS job-list operation. S3/SNS/IAM/KMS/A2I
references are explicit rather than enumerating other services. Start/get actions retain JobId,
NextToken, status, warnings and partial/failed results; they do not wait or concatenate pages.
