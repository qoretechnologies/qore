connection **`assemblyai`**. Valid authenticated pings pass; a deliberately invalid key fails.
The named connection exposes all 33 children and performs a typed transcript listing.

alternative authentication is rejected.

recognition.” It was generated locally with eSpeak NG. Upload, submit/poll, get, sentence/paragraph
retrieval, SRT export, word search, Sync STT, finite live upload, dictation, and incremental native
upload succeeded. Created transcript resources were deleted; no pre-existing resource was deleted.

tokens, voice agent tokens, and Qwen chat completion. Native speech WebSocket established a session,
accepted termination, and returned its final turn and termination events without audio. Native chat

using both credentials and `--native` passed all four registered authentication/read/session cases
with 21 assertions. The two synthetic-audio cases had already passed with 12 assertions before that
remote update; they were not repeated merely to incur additional transcription charges.
