results are typed alternatives with an open protobuf Any alternative for future service types.
This deliberately follows the shared schema design rather than duplicating each vendor schema as a
handwritten provider-local type.

## Implementation review

Authentication now belongs to both REST clients and covers sync/async, raw, future, copy, generic,
reference, and helper requests. GcpAuth remains the only production token broker; production code never
invokes gcloud. Supported credential types are service-account and authorized-user files, plus metadata
credentials. External-account federation and impersonated credential files are explicitly unsupported.
Selected invalid credentials fail rather than silently falling through to another identity.

Token refresh/cache, quota-project precedence, bounded requests, safe token/header formats, disabled
redirects, and sanitized errors are tested. Resource and quota projects remain separate. Connection
constructors enforce required project, derive regional defaults, verify explicit regional consistency,
retain the connection scheme and app association, and make processor-list ping authenticate.
Malformed success bodies, 401, and 403 fail ping. The synchronous connect argument is honored.

Resource IDs are validated before single-segment encoding; full names must match project, location,
and dependent parent. Dropdowns are scoped and paginated, reject repeated tokens, and stop at 100 pages
or 10,000 resources. They do not enumerate private documents. Process input requires exactly one
nonempty bytes/file/GCS/inline-document source before optional coercion. Empty objects, false, and zero
are retained where valid. PATCH forms omit server-owned names and unrelated create requirements.
Batch forms validate source alternatives and output location. Waiting bounds both the overall deadline
and individual status request, preserves job identity/status on timeout, and returns final service
errors as operation data.

Shared enum defects are fixed in RestSchemaValidator, OpenApi3, and QoreDataField:
structured labels/descriptions survive adaptation, scalar allOf wrappers retain them, absent choices
remain absent, and values receive their declared scalar type when an AutoType placeholder is finalized.
Code-generation symbols from `x-enum-varnames` are not display labels. Explicit codec type replacements
remain valid; callers can replace old choices after replacing a scalar field with a structured form.
