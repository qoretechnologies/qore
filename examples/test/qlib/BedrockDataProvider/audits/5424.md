## Implemented behavior

The existing Bedrock connection now authenticates ping, control-plane, runtime, raw, and copied requests,
and routes each request to the correct regional endpoint. Canonical URI encoding is shared with
`AwsRestClient`, so values containing spaces, slashes, percent signs, plus signs, and Unicode characters are
signed exactly as transmitted. Runtime query strings route correctly, and routed clients and their copies
retain the owner of their shared connection manager after the root provider is released. Curated chat and
embedding requests send the exact JSON content and accept media types required by Bedrock.

The application exposes 118 actions: 108 control-plane operations, eight completed-response runtime
operations, the existing embedding action, and the generic API-call action. The three event-stream runtime
operations are deliberately excluded from completed-value data-provider actions and require a separate
streaming client. The Qore Bedrock client does not implement native event streaming; its chat callback emits
one completed response. Registration is idempotent, repeated/deferred discovery publishes the same exact
inventory, and initialization failures reach structured qualification state.

Schema-backed actions provide nested request and response types, unions, lists, maps, enums, constraints,
reference data, examples, mutation metadata, normalized paths, and distinct missing/null/empty/false/zero
values. Smithy document shapes and the generic `invoke-model` action preserve arbitrary JSON values,
including scalars, lists, objects, null, false, and zero. The original embedding
and generic actions retain their identities.

The recursive presentation graph contains 5,052 message IDs. Root English and all twelve standard locales
(`cs`, `de`, `es`, `fr`, `it`, `ja`, `ko`, `pl`, `sk`, `uk`, `zh-Hant`, and `zh-TW`) have exact ID and source
parity, nonempty translations, and protected code spans, URLs, and placeholders. Targeted regressions cover
Japanese labels, untranslated product names, and correct inference terminology. Reviewed app descriptions
state the native-streaming limit in every locale. Schema fingerprint changes renamed 116 nested IDs per
catalog through a verified bijection; existing flat identities were preserved.

## Live coverage and limits

The live check obtained short-lived environment credentials through `aws configure export-credentials`
without recording or displaying them. `BedrockRestConnection::ping()`, the schema-backed
`list-foundation-models` action, an authenticated Nova Micro `converse` request, the curated Titan embedding
action, and standalone `BedrockLlmProvider` and `BedrockEmbedder` requests all succeeded. The live client
suite also verified that invalid credentials fail ping. No credentials were committed.

The development credentials and region did not provide every optional Bedrock feature, model entitlement,
or mutating-resource permission. Those operations are covered by exact schema, metadata, request routing,
serialization, and mock-transport tests. The three event-stream runtime operations are an intentional,
documented boundary of the completed-value action framework rather than incomplete action implementations.
