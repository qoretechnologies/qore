Root causes
-----------

* Three ProviderIndex worker tests accepted process 2.1 while ProviderIndex requires 2.2.
* The Ubuntu core shows the signal thread in SafeLocker::lock() after sigtimedwait(), while the main thread destroys globals from C exit(). Signal TID 0 is excluded from the application-thread count, so it was never joined on this exit path.
