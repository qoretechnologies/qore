Module documentation navigation audit
=====================================

Copyright 2026 Qore Technologies, s.r.o.

Imported tag files contain both public API symbols and guide pages. Doxygen's
EXTERNAL_PAGES default allowed the shared SDK language index to populate module
sidebars with Qore's own pages. New development pages, including Fast Text
Processing, have no corresponding page at the published current-documentation
URL. The reported URL returned HTTP 404. Doxygen 1.16.1 exposed these entries in
11 documentation sets across VSS, SSH, Cairo, and Markdown.

All ten maintained CMake, Autotools, and installed-SDK Doxygen templates now set
EXTERNAL_PAGES and EXTERNAL_GROUPS to NO. Explicit references still use the
unchanged tag files. Local pages and groups remain in navigation. The design
policy documents this distinction.

Validation
----------

* Navigation regressions pass with Doxygen 1.9.5 and 1.16.1. They cover all ten
  templates, imported pages, intro sections, groups and API classes, local pages
  and groups, absolute and relative tag destinations, and paths with spaces.
* All 11 installed-SDK tests and seven two-phase build tests pass.
* Complete docs builds pass without warnings or errors for VSS, SSH, Cairo, and
  Markdown. VSS's three documentation regressions pass, and four mainpages pass
  the layout check. The rendered-reference scan passes on 671 HTML files.
* Explicit imported cross-references are preserved on all 120 baseline pages.
  Qorus's VSS, SSH, and Cairo paths resolve to the rebuilt files. Markdown's local
  documentation is rebuilt; it has no entry in that composed Qorus tree.
* All 119 current external-module sidebars are free of imported Qore guide
  entries. Their 22,026 local navigation destinations and anchors resolve.
  A stale QorusSshIntegration documentation tree, no longer generated by the
  SSH build, was retained with the other old HTML under a temporary backup.
* Cairo's configure-time warnings are fixed by adopting CMake policies through
  3.31 and supplying the missing manifest-based uninstall helper. Its three tests
  cover missing manifests, directories, staged paths with spaces, dangling links,
  preservation of unrelated files, and repeated uninstalls.
